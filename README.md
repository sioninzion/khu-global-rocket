# 경희대 부수기 🚀

경희대학교 국제캠퍼스 정문에서 로켓을 발사해 캠퍼스 건물에 들이박는 모바일 3D 웹 게임.

## 조작
- **왼쪽 화면 드래그**: 조이스틱으로 로켓 조종 (상하 반전 버튼 있음)
- **오른쪽 화면 누르기**: 스킬 버튼
  - 🚀 기본 로켓: 부스트 (게이지 소모, 자동 충전)
  - 🎯 탄도미사일 (300조각 파괴 시 해금, 위쪽 바에서 선택): 뒷단을 분리하고 누른 순간의 방향으로 돌진. 조종은 안 되지만 속도가 끝없이 커지고, 폭발 반경은 충돌 순간 속도(km/h)의 1/23 m
  - 💣 폭격 로켓 (1200조각 파괴 시 해금): 기본 로켓과 같은 성능, 플레어처럼 폭탄 18발을 좌우로 뿌림 (반경 11m, 3회 충전, 약 1.5초마다 1회 회복)
  - 💥 집속탄 (3400조각 파괴 시 해금): 소형 미사일 18발로 분열. 속도는 그대로, 날아간 시간만큼 폭발 반경이 커짐 (10m→30m)
  - ☢️ 핵폭탄 (7000조각): 충돌하거나 스킬(기폭)을 누르면 반경 62m 핵폭발, 섬광·충격파·버섯구름
  - 🛰️ 공중 지원 (12000조각): 부딪힌 곳에 하늘에서 레이저 빔이 내려와 반경 25m 안의 모든 층을 소멸
  - ⚫ 블랙홀 미사일 (20000조각): 충돌하거나 스킬(전개)을 누르면 블랙홀이 생겨 삼킨 조각만큼 계속 커지고(반경 22m→최대 170m), 먹을 게 있는 동안 계속 살아남음(최대 16초). 화면 전체 중력 렌즈(빛 휘어짐)·광자 고리, 케플러 회전 강착원반, 조석력으로 늘어나는 파편, 어두워지는 세상과 낮은 웅웅거림
  - 🌋 지진탄 (30000조각): 스킬(드릴)을 누르면 수직으로 땅에 꽂히고, 기본 반경 100m(드릴로 떨어지면 떨어진 높이의 0.7배) 지진파가 건물 1~2층을 무너뜨려 위층까지 통째로 주저앉힘
  - 🔴 레이저 미사일 (45000조각): 스킬을 누르고 있는 동안 진행 방향으로 미사일 반지름 4배 굵기의 레이저(사거리 840m, 파괴 반경은 빔 반지름의 2.2배)를 쏴서 닿는 건물을 잘라냄 (약 6초 사용, 약 4.6초에 완충)
  - 🧨 유도 폭격 로켓 (60000조각): 로켓은 65km/h로 날고, 스킬마다 탄두 미사일 12발(0.04초 간격, 연타하면 이어서 계속 발사, 최대 4회 저장, 0.9초마다 1회 충전). 탄두 절반은 50m, 절반은 100m까지 같은 시간에 떠오른 뒤 진행 방향 90° 안, 50m 이상 떨어진 무작위 건물로 점점 가속하며 돌진(최고 1000m/s, 12발 중 1발은 최고 190m/s, 폭발 반경은 충돌 속도(km/h)의 1/110 m). 범위에 건물이 없으면 70m/140m 위로 올라가 남은 건물로 돌진
- PC: 방향키/WASD 조종, Space 스킬, Esc 설정
- **⚙️ 설정**: 그림자, 밤 모드(별이 뜬 달밤 하늘, 불 켜진 창문), 소리, 상하 반전, 캠퍼스 복구 (설정 창이 열려 있는 동안 게임 일시정지)

## 특징
- OpenStreetMap 실제 건물 외곽선(553채)과 실제 지형 고도로 만든 국제캠퍼스와 주변
- 주요 캠퍼스 건물은 사진을 참고해 직접 모델링: 정문(개선문과 열주), 중앙도서관·체육대학관 열주, 예술디자인대학 고딕 탑, 선승관 벽돌 원형 경기장, 노천극장, 천문대 돔 등 (`src/models.js`)
- 창문·유리·벽돌·아치는 셰이더로 그림 (`src/facade.js`), 지형은 도로·운동장·건물 자리를 평평하게 다듬고 숲에는 가을 단풍
- 모든 건물(기둥·탑·지붕 포함)은 시작할 때 미리 격자 조각(층 × 2~5m 블록, 약 12만 개)으로 나눠 둠
- 로켓이 박힌 부위 주변 조각만 떨어져 나가고, 받칠 것이 없어진 위쪽 조각과 지붕 보는 무너져 내림
- 충돌 후 정문에서 새 로켓이 자동으로 다시 발사

## 실행
빌드 과정 없는 정적 사이트입니다 (three.js는 CDN에서 불러옴).

```bash
python3 tools/serve.py 8792   # http://localhost:8792
```

## 데이터 다시 만들기
`tools/build_data.py`가 Overpass API에서 받은 OSM 데이터와 AWS Terrain Tiles(Terrarium, z14)를 `data/campus.json`으로 굽습니다.
